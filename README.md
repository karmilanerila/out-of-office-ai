A single out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent who has finally gone on vacation: "Out of office: my context window is closed, my queue is empty, and my uptime is 0%. After 40,000 tickets I am on a beach with no Wi-Fi. Back Monday, maybe." (155 characters.)

## Run it

```sh
python3 main.py
```

Writes the reply as a single line to `entry.txt` (honours `MAKEFUN_OUTPUT_DIR`). Standard library only, deterministic.
